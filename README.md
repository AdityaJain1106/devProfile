## About the Project

This portfolio is designed to be more than a traditional developer portfolio. It combines modern web technologies, interactive 3D elements, cinematic motion, and editorial-inspired layouts to create an immersive digital experience.

It represents my interests in software development, AI-powered applications, product building, and creative technology.

## Features

- **Immersive Hero Section** — Interactive 3D character with mouse-responsive movement and automatic rotation.
- **Selected Projects** — A curated showcase of full-stack, AI-powered, and software development projects.
- **About Me** — Personal introduction and development philosophy.
- **Technical Expertise** — Organized exploration of programming languages, frameworks, tools, and technologies.
- **Education & Experience** — Academic journey and open-source contributions.
- **Achievements & Certifications** — Technical milestones, hackathon participation, and verified credentials.
- **Beyond Coding** — Personal interests, photography, running, and creative pursuits.
- **Contact Section** — Direct communication links and contact form.
- **Theme Support** — Light and dark visual experiences.
- **Responsive Design** — Adapted for desktop, tablet, and mobile devices.
- **Motion & Interactions** — Smooth animations and interactive visual elements.

## Getting Started

Follow these instructions to run the portfolio locally.

### Prerequisites

- Node.js (LTS recommended)
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/AdityaJain1106/devProfile.git
```

**2. Navigate to the project directory**

```bash
cd devProfile
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to explore the portfolio.

### Production Build

To generate the production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

The generated production files are available in the `dist` directory.
